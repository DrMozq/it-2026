# npm

Презентация по теме **npm** (Node Package Manager) для дисциплины «Интернет-технологии». Поляков В.В. 5040102/60201

## Содержимое каталога

- `npm.pdf` – pdf-версия презентации.
- `src/` – исходный код демонстрации, которая показывается в презентации.
  - `package.json` – описание проекта и его зависимостей (`lodash`).
  - `package-lock.json` – точные версии всех установленных пакетов.
  - `index.js` – небольшая программа, использующая библиотеку `lodash`.
  - `.gitignore` – исключает папку `node_modules` из репозитория.

## Как запустить демонстрацию

Нужен установленный [Node.js](https://nodejs.org) (npm устанавливается вместе с ним).

```
cd src
npm install    # установить зависимости из package.json
npm start      # запустить index.js
npm audit      # проверить зависимости на известные уязвимости
```

Команда `npm ci` вместо `npm install` ставит зависимости строго по `package-lock.json`.
