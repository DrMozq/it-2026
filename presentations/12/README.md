# npm

Презентация по теме **npm** для дисциплины «Интернет-технологии».

## Содержимое каталога

- `npm.pdf` – pdf-версия презентации.
- `src/` – исходный код демонстрации: веб-приложение «Список задач».
  - `package.json` – описание проекта, зависимостей и скриптов (поле `"type": "module"` включает ES-модули).
  - `package-lock.json` – точные версии всех установленных пакетов.
  - `server.js` – запуск сервера.
  - `app.js` – приложение на Express: REST API для списка задач.
  - `public/` – страница (`index.html`) и скрипты браузера: `main.js` (интерфейс), `api.js` (запросы к серверу), `format.js` (формат даты).
  - `test/app.test.js` – тесты API.
  - `.gitignore` – исключает папку `node_modules` из репозитория.

## Что используется из npm

| Пакет | Вид зависимости | Для чего |
| --- | --- | --- |
| `express` | dependencies | веб-сервер и маршруты API |
| `dayjs` | dependencies | форматирование даты в браузере (файл отдаётся из `node_modules` и подключается обычным скриптом) |
| `supertest` | devDependencies | проверка API в тестах |

## Модули

Весь код написан как ES-модули (`import` и `export`). Для сервера их включает поле `"type": "module"` в `package.json`, для страницы – атрибут `type="module"` у тега `<script>`. В ES-модулях Node.js в путях к своим файлам нужно писать расширение (`./app.js`).

## Скрипты

| Команда | Что делает |
| --- | --- |
| `npm start` | запускает сервер (`node server.js`) |
| `npm run dev` | запускает сервер с перезапуском при изменении файлов |
| `npm test` | запускает тесты |
| `npm run audit:check` | проверяет зависимости на известные уязвимости |

## Как запустить

Нужен установленный [Node.js](https://nodejs.org) версии 18 или новее. В некоторых дистрибутивах Linux npm ставится отдельным пакетом.

```
cd src
npm install        # установить зависимости из package.json
npm test           # запустить тесты
npm start          # запустить сервер
```

После запуска приложение доступно на http://localhost:3000.

Команда `npm ci` вместо `npm install` ставит зависимости строго по `package-lock.json`.
