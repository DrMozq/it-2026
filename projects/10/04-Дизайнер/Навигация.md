# Навигация по интерфейсу

## 1. Введение
Настоящий документ содержит диаграмму состояний пользовательского интерфейса веб-приложения для организации онлайн-обучения и тестирования, определяющую экраны системы, модальные состояния и логику переходов между ними.

---

## 2. Диаграмма состояний интерфейса верхнего уровня

```mermaid
stateDiagram-v2
    direction TB

    [*] --> ГостеваяЗона: Открытие веб-приложения

    state "Гостевая зона" as ГостеваяЗона {
        [*] --> КаталогОткрытыхКурсов
        state "Каталог открытых курсов" as КаталогОткрытыхКурсов
        state "Просмотр карточки курса" as ГостеваяКарточкаКурса
        state "Модальное окно: Вход" as ОкноВхода
        state "Модальное окно: Ошибка аутентификации" as ОшибкаАутентификации
        state "Модальное окно: Регистрация" as ОкноРегистрации
        state "Модальное окно: Ошибка регистрации" as ОшибкаРегистрации
        state "Модальное окно: Подтверждение отправки письма" as УспехРегистрации

        КаталогОткрытыхКурсов --> ГостеваяКарточкаКурса: Клик по карточке курса
        ГостеваяКарточкаКурса --> КаталогОткрытыхКурсов: Клик «Назад к каталогу»
        ГостеваяКарточкаКурса --> ОкноВхода: Клик «Записаться на курс»

        КаталогОткрытыхКурсов --> ОкноВхода: Клик «Войти»
        ОкноВхода --> КаталогОткрытыхКурсов: Клик «Закрыть»
        ОкноВхода --> ОшибкаАутентификации: Отправка формы [Данные неверны / 401]
        ОшибкаАутентификации --> ОкноВхода: Клик «Повторить ввод»

        КаталогОткрытыхКурсов --> ОкноРегистрации: Клик «Регистрация»
        ОкноРегистрации --> КаталогОткрытыхКурсов: Клик «Закрыть»
        ОкноРегистрации --> ОшибкаРегистрации: Отправка формы [Данные некорректны / Email занят]
        ОшибкаРегистрации --> ОкноРегистрации: Клик «Исправить данные»
        ОкноРегистрации --> УспехРегистрации: Отправка формы [Данные валидны]
        УспехРегистрации --> КаталогОткрытыхКурсов: Клик «Понятно»
    }

    state "Кабинет студента" as КабинетСтудента
    state "Кабинет преподавателя" as КабинетПреподавателя
    state "Кабинет администратора" as КабинетАдминистратора

    ОкноВхода --> КабинетСтудента: Успешная аутентификация [Роль: Студент]
    ОкноВхода --> КабинетПреподавателя: Успешная аутентификация [Роль: Преподаватель]
    ОкноВхода --> КабинетАдминистратора: Успешная аутентификация [Роль: Администратор]

    КабинетСтудента --> ГостеваяЗона: Клик «Выйти из аккаунта»
    КабинетПреподавателя --> ГостеваяЗона: Клик «Выйти из аккаунта»
    КабинетАдминистратора --> ГостеваяЗона: Клик «Выйти из аккаунта»
```

## 3. Декомпозиция состояний интерфейса

### 3.1. Гостевая зона

```mermaid
stateDiagram-v2
    direction TB

    [*] --> КаталогКурсов: Вход на сайт

    state "Каталог открытых курсов" as КаталогКурсов
    state "Просмотр аннотации курса" as КарточкаКурса
    state "Модальное окно: Форма входа" as ФормаВхода
    state "Модальное окно: Ошибка аутентификации" as ОшибкаВхода
    state "Модальное окно: Форма регистрации" as ФормаРегистрации
    state "Модальное окно: Ошибка регистрации" as ОшибкаРегистрации
    state "Модальное окно: Уведомление о подтверждении" as ПодтверждениеРегистрации

    КаталогКурсов --> КарточкаКурса: Выбор курса из списка
    КарточкаКурса --> КаталогКурсов: Кнопка «К списку курсов»
    КарточкаКурса --> ФормаВхода: Клик «Записаться на курс»

    КаталогКурсов --> ФормаВхода: Кнопка «Войти» в шапке
    ФормаВхода --> КаталогКурсов: Кнопка «Закрыть»
    ФормаВхода --> ФормаРегистрации: Ссылка «Создать аккаунт»
    ФормаВхода --> ОшибкаВхода: Кнопка «Войти» [Учетные данные не совпадают]
    ОшибкаВхода --> ФормаВхода: Кнопка «Попробовать снова»

    КаталогКурсов --> ФормаРегистрации: Кнопка «Регистрация» в шапке
    ФормаРегистрации --> КаталогКурсов: Кнопка «Закрыть»
    ФормаРегистрации --> ФормаВхода: Ссылка «Уже есть аккаунт»
    ФормаРегистрации --> ОшибкаРегистрации: Кнопка «Зарегистрироваться» [Ошибка валидации / Email занят]
    ОшибкаРегистрации --> ФормаРегистрации: Кнопка «Вернуться к форме»
    ФормаРегистрации --> ПодтверждениеРегистрации: Кнопка «Зарегистрироваться» [Данные корректны]
    ПодтверждениеРегистрации --> КаталогКурсов: Кнопка «Перейти в каталог»
```

### 3.2. Кабинет студента

```mermaid
stateDiagram-v2
    direction TB

    [*] --> МоиКурсы: Переход после авторизации

    state "Реестр: Мои курсы" as МоиКурсы
    state "Каталог курсов для зачисления" as КаталогСтудента
    state "Карточка курса: Программа и запись" as КарточкаЗаписи
    state "Окно подтверждения зачисления" as ПодтверждениеЗачисления
    state "Страница изучения занятия" as ИзучениеЗанятия
    state "Интерфейс прохождения теста" as ПрохождениеТеста
    state "Окно результатов: Тест сдан" as ТестСдан
    state "Окно результатов: Тест не сдан" as ТестНеСдан
    state "Просмотр сертификата" as ПросмотрСертификата
    state "Профиль студента" as ПрофильСтудента

    МоиКурсы --> КаталогСтудента: Вкладка «Найти курс»
    КаталогСтудента --> МоиКурсы: Вкладка «Мои курсы»
    КаталогСтудента --> КарточкаЗаписи: Выбор курса
    КарточкаЗаписи --> ПодтверждениеЗачисления: Клик «Записаться на курс»
    ПодтверждениеЗачисления --> КарточкаЗаписи: Зачисление подтверждено [Создана запись на курс]

    МоиКурсы --> КарточкаЗаписи: Клик «Продолжить обучение»
    КарточкаЗаписи --> ИзучениеЗанятия: Выбор доступного занятия
    ИзучениеЗанятия --> КарточкаЗаписи: Клик «Отметить как пройденное» / «К программе»
    ИзучениеЗанятия --> ИзучениеЗанятия: Клик «Следующее занятие»

    КарточкаЗаписи --> ПрохождениеТеста: Клик «Начать тестирование»
    ПрохождениеТеста --> ТестНеСдан: Завершение теста [Балл < проходного порога]
    ПрохождениеТеста --> ТестНеСдан: Истечение таймера [Балл < проходного порога]
    ПрохождениеТеста --> ТестСдан: Завершение теста [Балл >= проходного порога]
    ПрохождениеТеста --> ТестСдан: Истечение таймера [Балл >= проходного порога]

    ТестНеСдан --> КарточкаЗаписи: Клик «Вернуться к программе»
    ТестНеСдан --> ПрохождениеТеста: Клик «Повторить попытку»
    ТестСдан --> КарточкаЗаписи: Клик «К программе курса»
    ТестСдан --> ПросмотрСертификата: Клик «Получить сертификат» [Прогресс курса = 100%]
    КарточкаЗаписи --> ПросмотрСертификата: Клик по иконке сертификата [Курс завершен]
    ПросмотрСертификата --> МоиКурсы: Клик «К моим курсам»

    МоиКурсы --> ПрофильСтудента: Клик по аватару/профилю
    ПрофильСтудента --> МоиКурсы: Клик «Сохранить» / «Назад»
```

## 4. Спецификация переходов между состояниями

| Исходное состояние | Событие / Триггер | Сторожевое условие | Результирующее состояние | Действие системы |
|---|---|---|---|---|
| `[*]` | Загрузка веб-приложения | — | `Каталог открытых курсов` | Запрос и рендеринг списка опубликованных курсов |
| `Каталог открытых курсов` | Клик «Войти» | — | `Модальное окно: Форма входа` | Отображение диалогового окна аутентификации |
| `Модальное окно: Форма входа` | Клик «Войти» | Учётные данные неверны (401) | `Модальное окно: Ошибка аутентификации` | Вывод сообщения о неверном логине/пароле |
| `Модальное окно: Форма входа` | Клик «Войти» | Учётные данные верны, роль: Студент | `Реестр: Мои курсы` | Создание сессии, перенаправление в кабинет студента |
| `Модальное окно: Форма входа` | Клик «Войти» | Учётные данные верны, роль: Преподаватель | `Реестр курсов автора` | Создание сессии, перенаправление в кабинет преподавателя |
| `Модальное окно: Форма входа` | Клик «Войти» | Учётные данные верны, роль: Администратор | `Очередь модерации курсов` | Создание сессии, перенаправление в кабинет администратора |
| `Каталог открытых курсов` | Клик «Регистрация» | — | `Модальное окно: Форма регистрации` | Отображение диалогового окна с полями регистрации |
| `Модальное окно: Форма регистрации` | Клик «Зарегистрироваться» | Ошибки валидации / Email занят | `Модальное окно: Ошибка регистрации` | Подсветка полей с ошибками |
| `Модальное окно: Форма регистрации` | Клик «Зарегистрироваться» | Данные валидны, email уникален | `Модальное окно: Уведомление о подтверждении` | Создание неактивной записи, постановка письма в очередь |
| `Кабинет студента` | Клик «Выйти из аккаунта» | — | `Каталог открытых курсов` | Инвалидация токенов сессии, сброс контекста |
| `Карточка курса: Программа и запись` | Клик «Записаться на курс» | Запись отсутствует | `Карточка курса: Программа и запись` | Создание записи на курс (прогресс 0%), открытие доступа к урокам |
| `Страница изучения занятия` | Клик «Отметить как пройденное» | Занятие ранее не завершено | `Страница изучения занятия` | Сохранение отметки, пересчет процента прогресса курса |
| `Интерфейс прохождения теста` | Клик «Завершить тест» / Таймер 00:00 | Балл $\ge$ проходного балла | `Окно результатов: Тест сдан` | Фиксация успешной попытки, пересчет прогресса курса |
| `Интерфейс прохождения теста` | Клик «Завершить тест» / Таймер 00:00 | Балл < проходного балла | `Окно результатов: Тест не сдан` | Фиксация неуспешной попытки, вывод протокола ошибок |
| `Окно результатов: Тест сдан` | Клик «Получить сертификат» | Прогресс курса = 100% | `Просмотр сертификата` | Генерация и отображение бланка сертификата |
| `Форма создания курса` | Клик «Сохранить черновик» | Поля заполнены корректно | `Конструктор программы курса` | Создание записи курса со статусом «черновик» |
| `Конструктор программы курса` | Клик «Отправить на модерацию» | В курсе есть $\ge 1$ занятия и теста | `Реестр курсов автора` | Перевод курса в статус «на модерации» |
| `Экран проверки материалов курса` | Клик «Одобрить курс» | — | `Очередь модерации курсов` | Перевод курса в статус «опубликован» |
| `Экран проверки материалов курса` | Клик «Отправить замечания» | Замечания заполнены | `Очередь модерации курсов` | Возврат статуса курса в «черновик», отправка замечаний автору |

## 5. Матрица трассировки вариантов использования к экранным состояниям

| ВИ-3.2 | Изучение занятия и отметка о завершении | `Страница изучения занятия` |
| ВИ-3.3 | Прохождение проверочного теста | `Интерфейс прохождения теста`, `Окно результатов: Тест сдан`, `Окно результатов: Тест не сдан` |
| ВИ-3.4 | Получение сертификата | `Просмотр сертификата` |
| ВИ-4.1 | Создание курса | `Форма создания курса` |
