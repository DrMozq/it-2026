# Термины
Термин|Определение
---|---
Пользователь|Актор, взаимодействующий с приложением. Разделяется на два типа:  Гость (не прошедший авторизацию, аутентификацию) и Студент (авторизованный пользователь). 
Студент|Основной актор, использующий приложение для обучения моделей предиктивного анализа. Про него системе известны имя, пароль и email. Студентом становится пользователь, который прошел авторизацию.
Гость|Актор, не прошедший аутентификацию (не вошедший в учётную запись). Его возможности ограничены, он не может обучать модели, но ему доступны теоретические материалы. Про него ничего не известно.
Система|Веб-платформа для интерактивного знакомства с методами предиктивного анализа (ML Platform), предназначенная для изучения и практического применения методов предиктивного анализа. Содержит теоретические материалы и интерфейс для обучения моделей предиктивного анализа, само обучение модели происходит на сервере.
Предиктивный анализ|Направление анализа данных, использующее исторические данные для построения прогнозов будущих событий или значений.
Признак (feature)|Характеристика объекта из набора данных, используемая моделью как входная переменная при обучении.
Целевая переменная (target)|Переменная, значение которой модель должна предсказывать на основе признаков.
Гиперпараметр|Параметр алгоритма обучения, который задаётся пользователем до начала обучения (в отличие от параметров, которые модель подбирает сама в процессе обучения).
Модель|Результат обучения алгоритма на данных – объект, который по входным признакам выдаёт предсказание целевой переменной (для кластеризации – номер кластера).
Обучение модели (training)|Процесс подбора параметров модели на основе обучающей выборки данных.
Обучающая выборка|Часть набора данных, на которой модель обучается.
Тестовая выборка|Часть набора данных, не участвующая в обучении и используемая для проверки качества модели.
Метрика качества|Численный показатель, по которому оценивается, насколько хорошо модель решает задачу (например, точность, полнота, RMSE).
Линейная регрессия|Алгоритм, предсказывающий числовую целевую переменную как линейную комбинацию признаков.
Логистическая регрессия|Алгоритм классификации, предсказывающий вероятность принадлежности объекта к классу.
Случайный лес (Random Forest)|Ансамблевый алгоритм, строящий множество решающих деревьев и усредняющий их предсказания.
Метод k-средних (k-means)|Алгоритм кластеризации, разбивающий объекты набора данных на k групп (кластеров) так, чтобы объекты внутри кластера были близки к его центру.
Кластеризация|Задача разбиения объектов на группы схожих объектов без заранее известной целевой переменной.
Личный кабинет|Раздел платформы, доступный авторизованному пользователю, где хранятся данные профиля и история экспериментов.
Эксперимент|Атомарный процесс обучения и оценки модели на конкретном наборе данных с заданными гиперпараметрами и алгоритмом, инициируемый пользователем.
История экспериментов|Сохранённый список проведённых пользователем экспериментов с указанием алгоритма, настроек и полученных результатов.
CSV|Текстовый формат хранения табличных данных, используемый для загрузки пользовательских наборов данных на платформу.
