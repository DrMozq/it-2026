# Видение
### Тема проекта
**Веб-платформа для интерактивного знакомства с методами предиктивного анализа (ML Platform).**
## Описание
Веб-платформа предназначена для изучения и практического применения методов предиктивного анализа. Пользователь получает доступ к теоретическим материалам по алгоритмам машинного обучения и может применять изученные методы к собственным данным, без необходимости написания программного кода.

Платформа позволяет загрузить набор данных в формате CSV, выбрать необходимые признаки и целевую переменную, настроить гиперпараметры алгоритма и запустить обучение модели. После выполнения вычислений пользователь получает метрики качества и 
графическое представление результатов. В платформе рассматриваются линейная регрессия, логистическая регрессия, случайный лес и метод k-средних (k-means).

Для персонализации работы предусматривается создание учётных записей и личного кабинета пользователя с хранением связанных с пользователем данных в базе данных, включая историю проведённых экспериментов: использованные алгоритмы, настройки моделей и результаты обучения.

## Статус реализации

+ Информационный раздел с теорией по методам и метрикам – реализовано.
+ Загрузка CSV и обучение моделей (линейная регрессия, логистическая регрессия, случайный лес, k-means) – реализовано.
+ Отображение метрик качества и визуализация результатов (Plotly) – реализовано.
<br><br>
- Экспорт обученной модели.
- Регистрация, авторизация, личный кабинет.
- Сохранение и просмотр истории экспериментов.

## Целевая аудитория и роли

Основная аудитория – студенты IT-направлений и начинающие дата аналитики/ML-инженеры, которые хотят изучить и практически опробовать методы предиктивного анализа без необходимости писать код.
### Роли пользователей:
- Гость (неавторизованный пользователь) – доступ к 
информационному разделу (теория по методам и метрикам), без 
возможности загружать данные и обучать модели. Для проведения экспериментов необходимо зарегистрироваться.
- Студент (авторизованный пользователь) – полный доступ: загрузка данных, 
настройка и обучение моделей, визуализация результатов, личный 
кабинет с историей экспериментов.

Отдельная роль администратора в рамках проекта не предусмотрена – управление содержимым теоретического раздела не входит в задачи платформы.

## Границы проекта (что не входит в scope)

- Поддерживается только формат CSV для загрузки данных.
- Поддерживаются только 4 алгоритма: линейная регрессия, логистическая регрессия, случайный лес, метод k-средних (k-means) – добавление новых алгоритмов не планируется.
- Совместная работа над экспериментами (sharing, комментарии, 
совместные проекты между пользователями) не реализуется.
- Мобильное приложение не разрабатывается – только веб-интерфейс.

## Цели
### Доступное изучение методов предиктивного анализа
- Снизить порог входа для пользователей, не владеющих программированием.
- Совместить изучение теории с практическими элементами.
### Возможность практической работы с моделями машинного обучения
- Обеспечить работу с собственными наборами данных.
- Предоставить настройку гиперпараметров моделей.
- Обеспечить обучение выбранных моделей на сервере.
- Предоставить возможность скачать обученную модель.
### Наглядное представление результатов анализа
- Отображать метрики качества обученных моделей.
- Визуализировать результаты работы алгоритмов.
- Помогать пользователю оценивать влияние параметров модели на получаемый результат.
### Персонализированная работа пользователя с платформой
- Предоставить личную учётную запись.
- Обеспечить хранение истории проведённых экспериментов.

## Задачи

1. Разработать информационный раздел с теоретическими материалами по методам предиктивного анализа и метрикам оценки качества моделей. Реализовано.
2. Реализовать загрузку и обработку пользовательских наборов данных в формате CSV. Реализовано.
3. Реализовать настройку и обучение моделей линейной регрессии, логистической регрессии, случайного леса и метода k-средних (k-means). Реализовано.
4. Реализовать отображение метрик качества и визуализацию результатов обучения моделей. Реализовано.
5. Реализовать регистрацию, авторизацию и личный кабинет пользователя с хранением информации в базе данных.
6. Реализовать сохранение и просмотр истории проведённых пользователем экспериментов.
7. Реализовать экспорт обученной модели в файл.
