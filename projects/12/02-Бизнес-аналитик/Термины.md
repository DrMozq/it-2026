# Термины

Глоссарий предметной области RoomBook. Термины используются во всех артефактах в указанном значении.

| Термин | Определение |
|---|---|
| **Аудитория** | Помещение университета, которое может использоваться для занятий и мероприятий. Имеет номер, корпус, вместимость и набор оборудования. |
| **Корпус** | Здание университета, в котором находятся аудитории. Имеет адрес и часы работы. |
| **Аудиторный фонд** | Совокупность всех аудиторий, доступных для бронирования. |
| **Оборудование** | Технические средства аудитории: проектор, компьютеры, интерактивная доска, микрофон и т. п. |
| **Вместимость** | Максимальное число посадочных мест в аудитории. |
| **Основное расписание** | Учебное расписание занятий на семестр, утверждённое учебным отделом. Имеет приоритет над бронированиями. |
| **Занятие** | Запись основного расписания: аудитория, день недели, время, дисциплина, группа, преподаватель. |
| **Временной слот** | Интервал времени с началом и окончанием на конкретную дату. |
| **Бронирование** | Закрепление аудитории за пользователем на временной слот для определённой цели. |
| **Заявка на бронирование** | Бронирование в статусе «На рассмотрении» — ожидает решения диспетчера. |
| **Статус бронирования** | Текущее состояние бронирования: На рассмотрении, Подтверждено, Отклонено, Отменено, Завершено. |
| **Подтверждение** | Решение диспетчера (или автоматическое решение системы для преподавателя), после которого бронирование считается действующим. |
| **Отклонение** | Решение диспетчера отказать в бронировании; сопровождается причиной. |
| **Отмена** | Прекращение бронирования до его начала — по инициативе автора или диспетчера. |
| **Конфликт** | Ситуация, когда два бронирования или бронирование и занятие претендуют на одну аудиторию в пересекающееся время. |
| **Цель бронирования** | Причина использования аудитории: консультация, пересдача, собрание, мероприятие, самоподготовка и т. п. |
| **Студент** | Пользователь, обучающийся в университете. Его бронирования требуют подтверждения диспетчера. |
| **Преподаватель** | Пользователь — сотрудник, ведущий занятия. Его бронирования подтверждаются автоматически при отсутствии конфликта. |
| **Диспетчер** | Сотрудник учебного отдела, управляющий аудиторным фондом, расписанием и заявками. |
| **Личный кабинет** | Раздел приложения, где пользователь видит свои бронирования и уведомления. |
| **Уведомление** | Сообщение пользователю о событии (смена статуса бронирования, отмена из-за конфликта). |
| **Календарь занятости** | Представление аудитории (или списка аудиторий) с занятыми и свободными слотами на день или неделю. |
