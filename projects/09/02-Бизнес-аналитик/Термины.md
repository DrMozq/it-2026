# Термины

| Термин | Определение |
| --- | --- |
| ReviewGuard | Веб-сервис мониторинга и агрегации аномалий в отзывах о товарах и услугах с определением эмоциональной окраски. |
| Организация | Компания-клиент сервиса. Внутри организации хранятся объекты мониторинга, источники, отзывы, пороги и аномалии. Другие организации эти данные не видят. |
| Гость | Пользователь, который не выполнил вход. Может зарегистрировать организацию или войти. |
| Администратор организации | Участник, который добавляет товары и услуги, подключает источники, импортирует отзывы, задаёт пороги аномалий и управляет кодом приглашения. Создатель организации получает эту роль автоматически. |
| Аналитик | Участник организации, который смотрит дашборд и ленту, получает оповещения и разбирает аномалии. |
| Учётная запись | Запись о пользователе: имя, email и пароль. Пользователь состоит не более чем в одной организации. |
| Код приглашения | Код, по которому новый пользователь присоединяется к организации с ролью аналитика. Администратор может отозвать код, после этого старый код не действует. |
| Объект мониторинга | Товар или услуга, по которым организация собирает отзывы. Имеет название, тип (товар или услуга) и необязательное описание. |
| Источник | Место публикации отзывов об объекте: название площадки и ссылка на карточку. К одному объекту можно подключить несколько источников. |
| Отзыв | Сообщение покупателя или клиента. Содержит текст, дату (если она есть в выгрузке), источник, объект мониторинга и необязательные поля: автор, оценка площадки, ссылка на отзыв. |
| Выгрузка CSV | Файл табличных данных с отзывами площадки. Обязателен столбец с текстом. Дата, автор, оценка и ссылка необязательны. |
| Тональность | Эмоциональная окраска текста отзыва. Три класса: позитивная, нейтральная, негативная. |
| Уверенность классификатора | Числовая оценка того, насколько классификатор уверен в выбранной метке тональности. |
| Классификатор тональности | Встроенная модель сервиса, которая по тексту отзыва проставляет тональность. Пользователь модель не обучает. |
| Спам | Отзыв, у которого в окне наблюдения по тому же объекту есть несколько таких же или почти таких же текстов. Пометка нужна, чтобы видеть накрутку и однотипный вброс. |
| Окно наблюдения | Последние 24 часа. В этом интервале сервис считает текущий негатив и спам. |
| Базовый период | 7 суток непосредственно перед окном наблюдения. По нему считается обычный фон негативных отзывов. |
| Агрегат | Сводный показатель по объекту или организации: число отзывов, доли тональностей, число пометок спама, разрез по источникам и по времени. |
| Аномалия | Зафиксированное отклонение потока отзывов от обычного фона. Бывает двух типов: аномалия негатива и аномалия спама. |
| Аномалия негатива | Событие, при котором в окне наблюдения негативных отзывов не меньше заданного минимума и их число заметно выше фона базового периода. По умолчанию минимум — 5 отзывов, превышение фона — в 2 раза. |
| Аномалия спама | Событие, при котором в окне наблюдения отзывов с пометкой «спам» не меньше заданного минимума и их доля не ниже порога. По умолчанию минимум — 5 отзывов, доля — 30%. |
| Порог аномалии | Настраиваемые администратором числа: минимум отзывов, коэффициент превышения фона и доля спама. Пока порог не изменён, действуют значения по умолчанию. |
| Статус аномалии | Состояние разбора: «открыта», «подтверждена» или «ложная». |
| Карточка аномалии | Экран с типом аномалии, объектом, окном, показателями и списком отзывов, из которых она сложилась. |
| Дашборд | Главная страница участника организации. Показывает объём отзывов, распределение тональности, динамику и открытые аномалии. |
| Лента отзывов | Список отзывов организации с фильтрами по объекту, источнику, тональности, спаму и периоду. |
| Оповещение | Сообщение внутри сервиса о том, что открыта аномалия. Письма и мессенджеры для оповещений не используются. |
| Профиль | Раздел с именем и email пользователя и сменой пароля. |
